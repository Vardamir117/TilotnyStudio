Place Holocron.exe into the data folder of a Workshop or local Empire at war mod.
Place Tilotny.exe into a subfolder of the data folder (e.g. data/Tilotny)

Alternatively, place a debugpaths.cfg in the same directory as the executables, with the following lines:
path to the Forces of Corruption mods folder
path to the workshop folder
Any number of stacking mods in descending load priority

e.g.
C:\Program Files (x86)\Steam\steamapps\common\Star Wars Empire at War\corruption\Mods
C:\Program Files (x86)\Steam\steamapps\workshop\content\32470
C:\Games\EaWmods\Imperial_Civil_War21\Data
C:\Program Files (x86)\Steam\steamapps\common\Star Wars Empire at War\corruption\Data
C:\Program Files (x86)\Steam\steamapps\common\Star Wars Empire at War\GameData\Data
